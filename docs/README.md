# Documentation

Start with [installation](installation.md), [data preparation](data-preparation.md),
[recipes](recipes.md) and [acceptance testing](acceptance.md).

[Developer documentation](developer/README.md) links current architecture,
scientific guides and designs. Work history belongs in
[GitHub issues](https://github.com/fselman/wenu-imaging/issues) and pull requests.
External manuals, papers and standards are reference material, not required reading
for ordinary use. Configuration contracts under `architecture/` include executable
schemas/examples used by the software; they are not disposable work reports.
