\section*{Executive summary}
For each detector, load calibrations and raw planes once, capture raw evidence,
scan-correct, trim, subtract the supplied active master from flats and retain one
processed cube. If an input BPM is supplied, log the skip; otherwise create a
robust response BPM. Measure linearity ROIs, pairs and direct sites from that
same cube, publish FITS/ASDF, then release it. Linearity is measurement only:
no physical response correction, shutter solution or gain conversion is applied.

\textbf{Qualification status.} Native TOML admission and the unified command are
implemented. Local synthetic numerical/help checks pass; Mac native-ASDF and
observational qualification of this interface remain required before selection.

\section*{Command and help}
Run from orchestration; reference a project TOML and use a fresh empty reduced run.
The recipe command processes and publishes the requested products:
\begin{verbatim}
mefpp_recipe cal bpm-linearity --config RECIPE.toml --qc false

mefpp --help
mefpp_recipe cal --help
mefpp_recipe cal bpm-linearity --help
mefpp_recipe cal linearity --help
mefpp_recipe cal bias --help
\end{verbatim}
Top-level help identifies commands; category help lists all recipes (including
explicitly pending entries); each implemented
operation reports its inputs, options, defaults and outputs. Help requires no
configuration or observation files and performs no processing.

\section*{Inputs and directory contract}
Project TOML defines raw, calibration, reduced, work and log roots; its containing
directory is orchestration. Raw observations and input calibrations are read-only.
Lists/TOMLs belong in orchestration; products, private work, logs and receipts
belong below reduced. The recipe selects ordered flats and bias evidence, explicit
pairs/times, master-bias and optional BPM bindings, detector/HDU/configuration-slot
mappings, ROIs and direct sites. These identities are distinct; HDU order does not
supply a detector mapping. No directory-based input discovery is implied.

Native schema 2 reads ordinary recipe inputs directly; historical sample archives
and handoffs are not prerequisites. A supplied master with its SHA256 and explicit
bias membership is required; no zero substitute or automatic dependency reduction
is used. Historical comparison remains a separate saved-data check. The WFI
example is a provisional two-level engineering test; its fingerprint, membership
and proposed site must be reviewed before execution.

Each detector declares \texttt{master\_bias}, \texttt{master\_hdu},
\texttt{master\_sha256}, \texttt{bias\_accepted}, reference ROI IDs, direct
\texttt{sites} (ROI, active x/y), and pixel/row bounds. \texttt{input\_bpm} is
an explicit calibration path with \texttt{bpm\_hdu}, or \texttt{omitted}.
Common \texttt{hdu} is required; optional \texttt{flat\_hdus}/\texttt{bias\_hdus}
arrays override it per input. Raw paths use the project raw root; master/BPM paths
use its calibration root. Bias indices are 0 to $N_{\rm bias}-1$; omitted flat \texttt{input\_index}
defaults to $N_{\rm bias}$ plus flat ordinal. Explicit indices must be globally
unique; \texttt{asset} defaults to basename.

Optional \texttt{identity} defaults: \texttt{identity\_key=EXTNAME},
\texttt{amplifier\_key=-} (unused), bin keys
\texttt{HIERARCH ESO DET WIN1 BINX/BINY}, \texttt{exposure\_key=EXPTIME},
\texttt{exposure\_hdu=0}. Current profiles require 1x1 binning.

Processing TOML explicitly supplies scan switches, sampled scan rectangles,
low/high rejection counts, retained rectangles, ROI rectangles, saturation,
mask encoding/polarity/reject bits, pair-time tolerance, bias-admission/stack
controls and \texttt{with\_mad}. These have no silent instrument defaults.
OCAM examples use saturation 65534 ADU, rejection 10/10, bias range 0--1000 ADU,
stack kappa 2, minimum 3 frames, binary good value 1 and exact pair-time matching.
These are configured values, not universal detector properties.

\texttt{qc=false} skips optional BPM full-frame QC and MAD, retaining requested
ROI means, variances, populations, pair/direct-site data, traces and provenance.
\texttt{qc=true} respects the explicit \texttt{with\_mad} setting. Disabling MAD
does not disable medians required by the robust response algorithm. Unrequested
or unavailable statistics are marked unavailable, never filled with zero.

\section*{Per-detector processing and mask policy}
\begin{enumerate}
\item Validate ordered identities and geometry; load the supplied master and
optional input BPM once. Capture raw-only evidence during ingestion.
\item Correct each raw flat/bias plane once and retain corrected active images,
required raw planes/validity, identities and row traces in one owned detector cube.
\item If a BPM is supplied, skip creation and log \texttt{input\_bpm\_supplied}.
Otherwise fit a candidate from borrowed corrected flats and publish its FITS/QC.
\item Measure ROI, pair and direct-site data from that same cube. Release it
before proceeding to the next detector; assemble newly created BPMs afterward.
\end{enumerate}
The admitted input mask stays fixed; a generated candidate never feeds back into
this run's measurement populations. Explicit omission removes only the current
mask, preserving historical master/archive lineage. ROI populations can increase;
previously admitted direct values must remain exact and newly admitted sites are
reported separately. Whole-file preservation hashing still reads inputs before
and after the batch; numerical ingestion/correction alone is read-once.

\section*{Correction and measured quantities}
For frame $f$, row $y$, sorted enabled scan reads $v_{f,y,(k)}$, and rejection
counts $l,h$, the existing arithmetic is
\begin{align}
O_f(y)&=\operatorname{pix}\left[\frac{\sum_{k=l+1}^{n-h}v_{f,y,(k)}}{n-l-h}\right],\\
U_f(x,y)&=\operatorname{pix}[D_f(x,y)-O_f(y)], &
S_f(p)&=\operatorname{pix}[U_f(p)-B(p)]\quad\text{(flats only)}.
\end{align}
Scan summation/division use double precision; $\operatorname{pix}$ converts to
native \texttt{pixelvalue}. Preserve the separate subtraction roundings. Trim is
FITS 1-based inclusive; active row $j$ maps to raw row $j+y_{\min}-1$. Each raw row
uses its own scan reads, without smoothing or fitting. The master is already
scan-corrected/active and receives no further scan correction. Bias-role frames
have no master subtraction. Active BPMs do not mask electronic scan reads.

For each ROI, the common population $\mathcal P$ passes the fixed mask and
finite/raw-saturation checks in both flats and both reference biases. Each member
retains its own exposure time, identity and measurement. For $N=|\mathcal P|$:
\begin{align}
\bar S_i&=N^{-1}\sum_{p\in\mathcal P}S_{ip}, &
s_i^2&=\frac{\sum_{p\in\mathcal P}(S_{ip}-\bar S_i)^2}{N-1},\\
d_p&=\operatorname{pix}[S_{1p}-S_{2p}], &
s_d^2&=\frac{\sum_{p\in\mathcal P}(d_p-\bar d)^2}{N-1}.
\end{align}
Corrected counts must match admitted raw counts. For $N<2$, sample scatter is
unavailable. Save member variances, difference variance and $s_d^2/2$ distinctly.
Spatial variance is not automatically a noise weight or conversion-gain estimate.
Direct sites retain physical pixel values; ROI means do not replace them in a
nonlinear pixel model. Units remain ADU, ADU$^2$ and seconds.

Raw-pair diagnostics keep their original stage and common populations:
\begin{align}
\mathrm{RON}_{\rm ADU}&=\sqrt{v(B_1-B_2)/2},\\
\mathrm{RON}_{\rm MAD}&=\frac{1.4826}{\sqrt2}
 \operatorname{median}|\Delta B-\operatorname{median}\Delta B|,\\
g&=\frac{\bar F_1+\bar F_2-\bar B_1-\bar B_2}
{v(F_1-F_2)-v(B_1-B_2)}\quad[\mathrm{electrons/ADU}].
\end{align}
Here $v$ is ordinary sample variance on the declared raw population; MAD is
optional. Gain requires a positive denominator and suitable flat pairs; it is
a recorded diagnostic, not a conversion applied to the cube. Corrected
pair-difference variance must not be passed through this formula with a second
bias subtraction. Shared-master variance/covariance are unavailable; no physical
fit weights or uncertainties are invented from spatial scatter.

\section*{Robust response BPM}
For corrected flat $j$, the reference level $x_j$ is the existing native median
of finite eligible pixels in the union of reference ROIs. Prior-mask selection
controls the reference population, not whether a pixel is evaluated for defects.
Per-pixel valid/unsaturated samples fit the existing Eclipse robust line:
\begin{align}
S_{pj}&\simeq\alpha_p+\beta_px_j, &
A_p&=N_p^{-1}\sum_j|S_{pj}-\alpha_p-\beta_px_j|,\\
R_p&=\operatorname{pix}\left[\beta_p/
 \operatorname{mean}_{q\in G}\beta_q\right].
\end{align}
$G$ contains valid reference slopes. Preserve the fitter's median conventions,
native rounding and flagged least-squares fallback. $A_p$ is mean absolute
residual, not MAD. Unavailable fits have separate coverage states.

\section*{Flags, suitability and products}
Recipe \texttt{response\_low/high} set the current native float32 thresholds:
$R_p\leq\mathrm{low}$ sets bit value 4; $R_p\geq\mathrm{high}$ sets value 8.
The unflagged interval is strictly inside 0.5--1.5 by default. These are
\emph{dimensionless relative-response limits}, not electrons/ADU. The input
master's original configuration remains unchanged; save the current effective
thresholds separately in provenance.

The unsigned-byte registry defines the following meanings; the current response
fitter creates only values 4/8. Other tests require their own reviewed criteria.
\begin{center}
\begin{tabular}{r l r l}
\textbf{Value} & \textbf{Meaning} & \textbf{Value} & \textbf{Meaning}\\\hline
1 & Bias offset & 16 & Nonlinear response\\
2 & Dark current & 32 & Temporal noise\\
4 & Low/dead response & 64 & Instability\\
8 & Excess response & 128 & Premature saturation\\
\end{tabular}
\end{center}
Bits combine by OR. Zero means no detected reason, not certification. Coverage
is separate: 0 unavailable, 1 fitted, 2 flagged fallback. \texttt{new} output
contains newly measured reasons; \texttt{combined} requires a known reason-mask
prior. A binary prior cannot supply unknown historical reason bits.

Raw saturation and \texttt{upper\_fraction} limit usable samples; the upper
margin and minimum signal span are different controls. Quick mode requires at
least five usable pairs with five distinct times/paired levels; provisional mode
requires two levels. Save sample counts, signal coverage and pair mismatch.
For positive pair reference levels $x_1,x_2$, the saved mismatch is
$|x_1-x_2|/[(x_1+x_2)/2]$; compare it with
\texttt{maximum\_pair\_difference}. The shared-cube path records failed suitability and continues measuring; it does
not relax thresholds, erase evidence or declare a scientifically accepted BPM.

\begin{tabular}{p{.27\linewidth}p{.66\linewidth}}
\textbf{Product} & \textbf{Contents}\\\hline
Detector BPM FITS & Reason image; \texttt{COVERAGE}, \texttt{NSAMPLE},
\texttt{NEWFLAGS}, \texttt{SELECTION}, optional \texttt{PRIORSEL}.\\
Detector ASDF & BPM QC, reason/coverage counts, settings, input/HDU mapping and
calibrations; linearity measurement ASDF retains ROI/pair/site data and traces.\\
Final BPM MEF/ASDF & Only newly created BPMs; none for an all-supplied-mask run.\\
Logs and \texttt{native-recipe.toml} & Stage/skip/failure messages, effective recipe, input preservation
and truthful completion. Failed work is retained.\\
\end{tabular}

BPM image products use \texttt{CMDP.<recipe-start>.001.fits} with matching ASDF/log names;
existing destinations are refused. A zero exit, completion receipt and independent
saved-product checks are required. Saved readers and viewers use measured ASDF
values without raw-pixel access or refitting. Separate exploratory residual
analysis and future shutter/linearity model specifications remain in their
separate guides linked from \path{docs/developer/README.md}; their eventual
consolidation is deferred. They are not steps in this measurement-only recipe.
Physical correction and cross-talk remain deferred.
