\section{Executive summary and authority}
The recipe estimates a master bias \emph{signal} by correcting the electronic
scan level separately in every input row, trimming the active rectangle,
rejecting entire frames by their corrected active-area means, and stacking the
retained frames with the existing Eclipse pixel median. QC describes the
inputs, corrections and master; it does not silently modify the result.

\textbf{Shared input contract.} Run \texttt{mefpp\_recipe cal bias --config RECIPE.toml}
from orchestration. The recipe references \code{project.toml}, numerical settings,
an absolute \code{inputs.list} path and a fresh reduced \code{run}. Each list row
contains an absolute FITS path under the project raw root and a \code{BIAS}
classification. The list directory is configurable. Calibration paths use the
project calibration root.
Optional BPMs are already reduced products. Dependency-list reduction is deferred.
The native archive preserves the classified list. Legacy \code{--bias} lists
remain compatible; new recipes use the same list contract as BPM/linearity.

This guide explains the implemented estimators and their source mapping.
Sparse source landmarks identify scientific stages without depending on line
numbers. Validation results and work summaries belong in GitHub issues and
pull requests; the guide describes the algorithm rather than its development
history.

This guide incorporates the already accepted average/lower temporal-median
choice and explicit zero-spread refusal. Optional clipped raw-pair RON is
explained in the companion guide \code{mathematics/mefpp/bias-clipped-ron.tex}
and its matching PDF; the median supplement is
\code{mathematics/mefpp/bias-median-even-handling.tex} and its matching PDF.
The designs in Section~\ref{sec:authority} retain the scientific authority.

All signal levels, standard deviations and read-noise diagnostics are in ADU.
Pixel and frame counts are dimensionless counts. The recipe performs no gain
conversion, flat normalization, interpolation or dark-current estimate.
It does not provide a master variance or a covariance model.

\subsection*{Three distinctions to retain}
\begin{enumerate}
\item The detector BPM selects physical active pixels. It is not applied to
electronic prescan or overscan samples.
\item Frame rejection selects complete exposures. The subsequent median stack
still evaluates every output pixel, including pixels excluded by that BPM.
\item Temporal stacking uses the configured average/lower even-sample policy.
Modern checked QC uses an averaged central pair; legacy telemetry helpers
retain their documented conventions. These roles must not be conflated.
\end{enumerate}
\subsection*{Mathematical description versus implementation}
Equations below state the estimators. Exact reproduction also requires the
documented order-statistic convention, evaluation order and pixel/float
conversions. Checked statistics retain the existing sum-of-squares
implementation; the guide does not substitute a different summation algorithm.

\section{Identity, coordinates and admitted inputs}
For one logical detector let $f=0,\ldots,F-1$ identify supplied raw frames
in their original order, and let $D_f(x,y)$ be a loaded value in ADU.
FITS scaling belongs to the existing loader; values entering this service
are the resulting \code{pixelvalue} samples.

Logical detector ID, source HDU, zero-based configuration index and output HDU
are independent bindings. In the retained OmegaCAM run CCD65 used configuration
index 0 and output HDU 1; CCD69 used index 16 and output HDU 17.
The actual source HDU is checked in each input, not inferred from its ordinal.

The trim rectangle is inclusive and one-based:
\[
 {\cal R}=[x_0,x_1]\times[y_0,y_1],\qquad
 W_A=x_1-x_0+1,\quad H_A=y_1-y_0+1.
\]
An active pixel $(i,j)$ refers to raw coordinate
\begin{equation}
 (x,y)=(x_0+i-1,\ y_0+j-1). \label{eq:coords}
\end{equation}
The code converts coordinates at the array-access boundary.
This pixel identity does not validate the legacy celestial WCS or supply
the deferred detector-layout fallback.

A binary BPM has an explicit HDU, polarity, coordinate domain, readout and
binning. The loader normalizes the declared good value to Eclipse polarity
$M=1$ for good and $M=0$ for excluded. Active-sized masks are embedded using
Equation~\eqref{eq:coords}; raw-sized masks are cropped consistently for active
measurements. Explicit omission is recorded; no mask is guessed from a filename.

\subsection*{Validation before calculation}
The service checks operation/version, detector/request bindings, common image
dimensions, scan/trim bounds, rejection counts, finite nonnegative frame
parameter $\kappa$, positive diagnostic parameter $k$, and minimum input count.
The configured minimum is at least three. The entire loaded raw plane must
contain finite values, including masked pixels. Malformed masks or contradictory
calibration declarations fail.

General statistics helpers can report nonfinite exclusions; this capability
does not relax the finite-raw-input rule. No raw saturation threshold or
automatic exposure discovery is added by this bias operation.

\subsection*{Code boundary}
\code{mef_layout_load}, \code{mef_layout_load_bpm} and binding checks handle
file/geometry identity. \code{mef_cal_bias_measurements} validates and calculates
one detector using copies, leaving caller raw planes and geometry unchanged.

\section{Electronic row correction}
For a raw row $y$, concatenate the enabled prescan and overscan column bands
into a vector $s_y$ of length $n_s$. No detector BPM is applied. If both bands
overlap, their common samples enter twice; the configuration must describe the
intended electronic samples. Disabled bands contribute nothing.

Sort the samples as $s_{y,(1)}\leq\cdots\leq s_{y,(n_s)}$. With integer low and
high rank-rejection counts $\ell,h$, the row correction is
\begin{equation}
 c_f(y)=\pix\left\{\frac{1}{n_s-\ell-h}
 \sum_{r=\ell+1}^{n_s-h}s_{y,(r)}\right\},\qquad n_s-\ell-h>0. \label{eq:scan}
\end{equation}
The sum uses double precision; the result is cast to the pixel type.
These are rank cuts, not iterative sigma clipping. Every column is corrected;
then the active rectangle is extracted:
\begin{equation}
 A_f(i,j)=\pix\{D_f(x_0+i-1,y_0+j-1)-c_f(y_0+j-1)\}. \label{eq:correct}
\end{equation}
The retained OmegaCAM configuration enables overscan only. CCD65 columns
2100--2142 contain 43 samples; rejecting ten at each end leaves 23.
Its active rectangle is $[51,2094]\times[5,4095]$, or $2044\times4091$ pixels.

The correction profile covers every raw row, including rows outside the trim.
Its legacy level is the pixel-median (Section~\ref{sec:medians}); its reported
RMS is a sample standard deviation about its own mean:
\[
 s_c=\sqrt{\frac{\sum_y(c_f(y)-\bar c_f)^2}{H_{\rm raw}-1}}.
\]
The implementation subtracts the median before the centered sum-of-squares
evaluation. This shift preserves the exact estimator. Legacy summaries pass
through float fields. Median selection reorders the working profile; scatter
is invariant to reordering. The bias record stores summaries, not an ordered
profile array. Separate raw scan QC uses enabled columns over trimmed rows.

\code{mef_overscan_correction_traced} corrects and crops;
\code{function1d_average_reject_checked} implements Equation~\eqref{eq:scan}.

\section{Frame admission and temporal stack}
Source: \code{mef_bias_kernel.c}, \code{mef_bias_stack_masked_diagnostic},
\code{[BIAS-FRAME-SELECTION]} and \code{[BIAS-TEMPORAL-STACK]}.

For each corrected active image, use all active pixels without a BPM, or only
its good pixels otherwise. The per-frame mean is
\[
 a_f=\frac{1}{N_f}\sum_{(i,j)\in{\cal G}_f} A_f(i,j).
\]
An empty valid population fails. The rejection band uses all $F$ submitted
frame means once:
\begin{align}
 \bar a&=\frac1F\sum_f a_f,&
 s_a&=\sqrt{\frac{\sum_f(a_f-\bar a)^2}{F-1}},\\
 L&=\bar a-\kappa s_a,& U&=\bar a+\kappa s_a.
\end{align}
The frame-band implementation accumulates centered squared deviations in a
second pass. Retain only $L<a_f<U$; equality at either boundary is rejected.
The band is not recalculated after rejection. The configured minimum number
of retained frames must be met. By the owner decision of 8 November 2026
(issue \#289), exactly $s_a=0$ is an explicit computation failure before
admission or stacking: the collapsed interval cannot admit any frame.
The native and legacy bias callers report the detector ID, every input filename
and its computed corrected mean (17 significant digits, ADU). The native service
also returns a specific zero-spread error and transfers no master. The recipe
stops before final FITS/ASDF publication and retains failure evidence.
The test uses the computed double-precision $s_a$, never its rounded legacy
float QC representation. No near-zero tolerance or inclusive endpoint rule is
introduced; every nonzero-spread case keeps the existing arithmetic.
The retained OmegaCAM setting is $\kappa=2$, minimum three frames.

Historical configuration entries \code{FRAMETHR.LO}/\code{FRAMETHR.HI}
do not add absolute cuts in this kernel. The computed band is operational.
For retained set ${\cal K}$, $K=|{\cal K}|$, the master is
\begin{equation}
 B(i,j)=\operatorname{med}_{\rm configured}
             \{A_f(i,j):f\in{\cal K}\}. \label{eq:stack}
\end{equation}
There is no per-pixel clipped mean or per-pixel rejection count.
The BPM selects frame-mean and QC populations; it does not replace output
pixels. The temporal median is evaluated at every active coordinate.
\code{mef_bias_stack_masked_diagnostic} selects frames and consumes the private
cube; \code{cube_avg_median_opts} implements the configured stack.
The stack allocates an independent master image. Once stacking succeeds, the
kernel releases the consumed corrected cube before master-statistics working
arrays are allocated, and clears its cleanup pointer. This changes no
estimator or numerical evaluation order; failures still release each owner
once. Ordinary in-memory calls keep borrowed raw images unchanged through the
service call. The file adapter uses \code{mef_cal_bias_owned_measurements}:
all validation and requested raw-pair diagnostics precede consumption; each
frame is copied and its raw/scan QC measured before its raw owner is released
and nulled, then correction proceeds on the private copy. No later stage reads
that raw view. On failure, adapter cleanup destroys remaining non-null owners.
Mismatched or shared pixel owners are rejected before consumption. This
reduces raw/corrected overlap without changing scientific evaluation order.
Releasing the corrected cube removes its overlap with master
statistics but cannot remove an earlier full-QC peak during per-frame
measurements. Resident memory also includes allocator and mapped-file state;
actual-host profiling remains necessary. The synthetic
\code{bias_memory_probe} checks release order in both QC profiles and can
capture compiler-local numerical snapshots for ten WFI-sized raw frames;
its optional final \code{owned} argument checks that no raw owners survive
to stacking. Failure injection covers partial consumption and caller cleanup.
QC retains original input IDs.

For synthetic frame means $0,1,2,10$ with illustrative $\kappa=1$,
$\bar a=3.25$, $s_a=\sqrt{62.75/3}\simeq4.573474$. The band is approximately
$[-1.323474,7.823474]$; the first three survive. This example uses $\kappa=1$
to expose the rule, not the retained setting 2.

\section{Median conventions and precision}\label{sec:medians}
For sorted $z_{(1)}\leq\cdots\leq z_{(N)}$, the modern checked QC median is
\[
 m(z)=\begin{cases}z_{((N+1)/2)},&N\text{ odd},\\
 \tfrac12 z_{(N/2)}+\tfrac12 z_{(N/2+1)},&N\text{ even}.\end{cases}
\]
The bias temporal stack defaults to \code{median_even_handling="average"}.
For even $K$, it uses $\tfrac12 z_{(K/2)}+\tfrac12 z_{(K/2+1)}$, evaluated
in double precision and converted once to \code{pixelvalue}. Explicit
\code{"lower"} uses $z_{(K/2)}$ for historical bias compatibility. Both modes
use the central order statistic for odd $K$. The bias stack requires at least
three retained frames. Selection follows the Wirth implementation documented
in the source \cite{wirth}; the existing timeline buffer is reused.

Ten retained frames therefore use the midpoint of the fifth and sixth sorted
samples by default, or the fifth in lower mode; nine frames use the fifth in
both modes. Generic Eclipse median callers retain their historical behavior:
the old pixel helper returns the lower central value for even $K\geq4$, while
its two-value case averages. The historical \code{double_median} helper uses
the upper middle for even samples. These helpers must not be substituted for
the configured temporal estimator or the modern checked QC median.

\subsection*{Legacy master statistics}
With a BPM, the kernel overrides the historical master median and standard
deviation with checked \emph{masked} statistics, then converts results to
float. They are not inherently unmasked. Without a BPM, the historical median
uses the pixel-median convention; modern QC averages the middle pair.
The explicitly named \code{master_unmasked} family always omits the BPM.
Even for equal definitions and populations, modern double results and legacy
float fields can differ through rounding.

The default \code{pixelvalue} is float; \code{DOUBLEPIX} selects a different
build lane. Scan sums use double precision but are converted to pixel type
before subtraction. Default FITS pixels are IEEE single precision. Existing
legacy cards retain six-decimal formatting; new scalar cards use 17 significant
digits with a FITS-compatible uppercase exponent. A short printed table cannot
establish exact numerical equality.

\subsection*{Worked order-statistic examples}
For $0,2,4,6$, modern QC and default temporal median are 3; explicit temporal lower mode gives 2.
For scan samples $100,101,102,103,200$ and one rank rejected at each end,
the correction is 102. Raw samples 110 and 112 become 8 and 10.

\section{QC calculation profiles}
The standalone recipe accepts \texttt{--qc full} or \texttt{--qc legacy}.
The TOML equivalent is \texttt{[bias] qc = "full"} or
\texttt{qc = "legacy"}. An explicit command-line choice overrides the TOML
choice; omission preserves \code{full}. Unknown or duplicate command-line
choices fail before processing.

Full QC defaults to MAD off: omitted \texttt{[bias] mad} means
\texttt{mad = false}, and omitted long-form \code{--mad} means \code{no}.
Explicit \texttt{mad = true} or long-form \code{--mad yes} opts in.
Clipped RON remains independent of this choice and follows its existing
configuration. MAD-based scatter, MAD RON and the MAD-based hot-pixel
diagnostic are unavailable when MAD is off; hot-pixel thresholds have not
been replaced by sigma-clipping. Other measurements keep their definitions.
Legacy QC retains the row-correction median/scatter and scan parameters,
frame-admission summaries and master median/scatter already produced by the
reduction. It skips the added raw-active, corrected-active and scan-region
sample statistics, raw-pair RON, clipped RON, MAD and high-offset diagnostics.
Expanded records remain present with null values and the reason
\code{disabled_by_legacy_qc}; they are not measured zeros. Cheap
configuration provenance remains available. The profile takes precedence
over MAD/RON measurement requests.

This is a measurement choice, not a pixel-processing preset. Input validation,
configured detector BPM use in frame admission, correction geometry,
rejection rules, temporal median convention and the existing master summary
estimators remain unchanged. In particular, requesting legacy QC does not
silently replace current masked frame means with the historical unmasked
means or select the lower temporal median. Comparisons with a historical
executable still require explicit matching settings and pixel checks.

Legacy products record \texttt{provenance.qc\_profile = "legacy"} in ASDF
and \texttt{ESO MPP QC PROFILE} in FITS. Absence of this optional field means
full QC for compatibility with existing products. Both modes retain FITS,
ASDF and log publication, membership/provenance and mandatory validation;
the switch allows numerical-QC comparisons within the same processing and
publication pipeline. Skipped diagnostics also reduce their associated
serialization work.

\section{Checked sample statistics and MAD}
A statistic defines its rectangle, processing stage, mask and nonfinite policy.
Within that rectangle, BPM-excluded pixels are counted first; among remaining
pixels, nonfinite samples are excluded. Thus region count equals BPM-excluded
plus nonfinite-excluded plus valid count. For valid values $z_1,\ldots,z_N$,
\begin{align}
 \bar z&=\frac1N\sum_i z_i, &
 s_z&=\sqrt{\frac{\sum_i(z_i-\bar z)^2}{N-1}},\\
 d_z&=m(\{|z_i-m(z)|\}),& \operatorname{sMAD}(z)&=1.4826\,d_z.
\end{align}
Both medians in $d_z$ use the averaged-middle convention. The raw MAD is scaled
exactly once. The constant approximates $1/\Phi^{-1}(3/4)$, making scaled MAD
consistent for normal-distribution standard deviation at large sample size
\cite{r-mad,nist-mad}. It is not a finite-sample unbiasedness correction, nor
does its use establish Gaussian detector noise.

Unlike the two-pass frame-band scatter, per-pixel sample helpers evaluate
\[
 v=\frac{\sum_i z_i^2-(\sum_i z_i)^2/N}{N-1},\qquad
 s_z=\sqrt{\max(0,v)}.
\]
They accumulate in double precision. Cancellation can affect nearly constant,
large-offset data; this guide records the current arithmetic rather than
replacing it with Welford accumulation. Legacy scan scatter uses the same
centered sum-of-squares family after its median shift.

The selective entry point
\code{image_getstats_masked_selected_checked} accepts independent
\code{IMAGE_SAMPLE_MEAN}, \code{IMAGE_SAMPLE_STDEV},
\code{IMAGE_SAMPLE_MEDIAN} and \code{IMAGE_SAMPLE_MAD} request bits.

\section{Read noise from the explicit raw pair}
Two distinct, explicitly selected original raw frames $a,b$ supply
\[
 \Delta(x,y)=D_a(x,y)-D_b(x,y),\qquad
 \operatorname{RON}_{s}=s_\Delta/\sqrt2,\quad
 \operatorname{RON}_{\rm MAD}=1.4826\,d_\Delta/\sqrt2.
\]
The population is the active rectangle with the intersection of good masks.
This is measured \emph{before} row correction or master subtraction. Selecting
a raw pair is independent of later stack admission: either selected frame can
be rejected from the master. \code{image_pair_stats_checked} forms the pixel-type
difference and invokes checked sample statistics.

For independent equal-variance noise, differencing doubles the variance.
More generally,
\[
 \Var(D_a-D_b)=\Var(D_a)+\Var(D_b)-2\Cov(D_a,D_b).
\]
The factor $\sqrt2$ therefore has an interpretation conditional on independence
and equal variance. Stable spatial bias structure cancels; temporal row drift
or other changing structure can contribute. Centering the difference for a
standard deviation is not equivalent to electronic row correction.
The generic sampled-window \code{image_rect_readout_noise} routine is a
different estimator and is not used for this bias diagnostic.

\subsection*{Quantization and repeated robust values}
For raw differences $-2,0,2,4$, the mean is 1 and
\[
 s_\Delta=\sqrt{20/3},\quad \operatorname{RON}_s=\sqrt{10/3}
 \simeq1.825742,\quad
 d_\Delta=2,\quad\operatorname{RON}_{\rm MAD}\simeq2.096713.
\]
Repeated values near 2.0967 ADU across detectors can result from the same
integer-valued MAD of 2. They do not demonstrate identical underlying noise.

\subsection*{Master uncertainty is not supplied}
This recipe supplies no master variance or covariance plane. In particular,
$\operatorname{RON}^2/K$ is not its implemented uncertainty model: the temporal
stack is a median, and row correction introduces shared estimates. For pixels
$p,q$ corrected using the same estimated row offset $c$,
\[
 \Cov(D_p-c,D_q-c)=\Cov(D_p,D_q)-\Cov(D_p,c)
 -\Cov(c,D_q)+\Var(c).
\]
This identity explains a possible correlation; the current product does not
estimate its terms or assume their independence.

\section{High-offset pixels}
With requested MAD, the selected master population gives median $m_B$ and
scaled MAD $s_{B,\rm MAD}$. For configured positive $k$,
\[
 T=m_B+k\,s_{B,\rm MAD},\qquad
 H(i,j)=\ind\{B(i,j)>T\},\qquad N_H=\sum_{i,j}H(i,j).
\]
The threshold population uses the declared BPM. The subsequent search visits
\emph{all} output pixels, including BPM-excluded ones, and uses strict $>$.
The direct flag loop has no additional finite-value filter. Finite raw-input
validation does not prove that every hypothetical floating-point overflow in
later arithmetic would remain finite.

Flag polarity is $1=$ flagged, unlike the normalized good-pixel BPM polarity.
Coordinates are one-based in the active output. This diagnostic does not
create or apply a new detector BPM. A high bias offset is not a dark-current
measurement, and $k=5$ does not by itself define a calibrated false-alarm rate.

A zero MAD is a measured but degenerate scale: the threshold becomes the median
and every larger output value qualifies. With MAD omitted the derived
threshold/count are unavailable. A measured zero count remains zero; an empty
coordinate set is represented with its explicit availability/reason context.

For master values $0,1,1,2,20$ with no exclusions, median and MAD are both 1.
At $k=5$, $T=1+5(1.4826)=8.413$ and only 20 is flagged. If 20 is BPM-excluded,
the threshold is recomputed from the remaining population, but the final search
still considers 20. This distinction is deliberate.

\section{FITS and ASDF: one measurement, two representations}
The accepted policy retains existing FITS QC cards and writes new scalar
diagnostics to both formats. Measurements and context are prepared from the
same common QC record. Neither writer independently remeasures pixels.
\code{mef_bias_qc_fits.def} is the authoritative field-to-card mapping.
The following summarizes families, rather than replacing that mapping.

A statistic carries unit, status/reason, stage, region, coordinate system, mask
identity/applicability, clipping and nonfinite policies, sample count and source
record references as applicable. An unavailable measurement has no invented
numeric card. Measured zero and unavailable are distinct.

The verified real product contained 89,445 mapped scalar/context cards:
$32\times2795+5$. These are not 89,445 independent numerical diagnostics.
Five detectors had one additional rejection-reason card. Arrays, embedded
input records and complete provenance remain in ASDF. FITS header scalars alone
do not reconstruct a full provenance tree. A future harvester must preserve
units, state and definitions, not merely collect numeric keyword values.

\section{Operation, publication and explicit recovery}
Normal operation keeps the raw directory untouched, launches orchestration
from its own directory and writes final reduced products to the explicit
product directory. In the retained run these were respectively
\code{/Users/fselman/Pictures/OCAM/bpm},
\code{/Users/fselman/Pictures/OCAM/test_recipes/orchestration}, and
\code{/Users/fselman/Pictures/OCAM/test_recipes/reduced/cal/bias}.

The standalone coordinator processes detectors serially: load and validate,
measure the raw pair, correct private frame copies, compute input QC, reject
frames, stack, and prepare common QC/header data. It writes private detector
products and releases detector-sized arrays. A single native writer assembles
the final MEF; the native QC writer publishes ASDF. A successful recipe requires
the required outputs to complete. Exclusive publication prevents silent
replacement; the FITS/ASDF/log set is not an atomic three-file transaction.

Expanded scalar/context headers exposed a former fixed 1 MiB aggregate
readback budget. The fix budgets the exact emitted, padded header bytes with
checked arithmetic while retaining the individual source-header bound.
Image payload bytes are not charged to the header budget. This repairs an
assembly limit; it does not change measured pixels or QC estimators.

The retained failed run was explicitly recovered from its private detector
products after verification. Recovery compared all pixel payloads and legacy
QC, checked mapped scalar/context cards against the original QC, then wrote a
native ASDF staging file and independently validated the complete record,
arrays and provenance before exclusive publication. It retained the failed
log and recovery identity. It did not retroactively declare the original
recipe successful or authorize unrestricted provenance harvesting.

The optional-cleanup change guards caller-side releases of absent optional
objects, covers repeated/partial cleanup and creation-name replacement, and
preserves allocator diagnostics for actual NULL misuse. It changes neither
these equations nor the global allocation contract.
