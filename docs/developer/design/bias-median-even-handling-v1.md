# Bias stacking median: even sample handling

Owner-approved contract, 7 November 2026, issue #287. The owner selected the parameter name `median_even_handling` and default `average`, then authorized implementation of the reviewed subroutine changes. This is a deliberate scientific change to bias stacking, not a zero-point normalization or a QC-only adjustment.

The recipe TOML accepts `[bias] median_even_handling = "average"` or `"lower"`. Omission defaults to average. Native processing TOML additionally accepts optional `MEF.BIAS.MEDIAN.EVEN.HANDLING` (schema 1/2) or the typed schema-3 `processing.bias_median_even_handling` descriptor; conflicting explicit authorities fail before products. Legacy PAF optionally accepts the same native key; omission also defaults bias stacking to average. No per-detector override or extra detector CLI blocks.

After detector-local scan correction and existing frame rejection, let x_(1)..x_(n) be one pixel's ordered retained samples. Odd n uses x_((n+1)/2) in both modes. Even n uses 0.5*x_(n/2)+0.5*x_(n/2+1) for average, and x_(n/2) for lower. Compute the midpoint in double then round once to working pixelvalue. No detector/mosaic centering, gain scaling or alteration of membership. Other Eclipse callers keep their existing median behavior through unchanged wrappers.

Add option-aware pixelvalue and cube median companions, using existing Wirth selection and the existing timeline buffer. For average select the upper central element and find the maximum of the partition's lower half. No per-pixel allocation, full sort, image copy, or second selection. Bias stack wrappers default to average; native and legacy bias paths explicitly pass effective mode.

Store the effective mode in the result, each detector's ASDF characterization and `ESO MPP QC MED EVEN` FITS card, including defaulted average. Preserve raw-pair RON/MAD/clipped RON and input QC unchanged. Spatial master QC is recomputed from the new detector pixels using its existing BPM/finite population; its averaged-middle median is already correct. Old ASDF records without the optional new field remain valid. Unknown/conflicting modes fail rather than falling back.

Qualification: independent sorted-oracle pixel/cube tests for odd/even counts, ties, permutations and finite extremes; unchanged generic wrappers; default average and explicit lower; actual bias kernels with even/odd accepted counts; strict lower-mode reproduction of historical reference pixels and existing QC, allowing explicit provenance additions only; independent recomputation of average-mode master statistics from products and BPM; exact unchanged raw/input diagnostics; FITS/ASDF mode agreement and snapshots; invalid/conflicting settings. Existing regression fixtures that intentionally require historical pixels explicitly request lower. Benchmark detector-sized synthetic stacks and retain operation-buffer accounting. Actual Mac uses the selected mutable source/build/cache/tools, not a new configuration/export; no observational rerun or installation is authorized by synthetic qualification.
