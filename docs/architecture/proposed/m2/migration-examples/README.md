# Source-preserving migration examples

Generated with the shared [migration API](../configuration-migration.md), not the
older test-only emitter. `omegacam.toml` and `wfi.toml` contain the exact native
stored settings returned by the original PAF constructor. `conversion-evidence.json`
retains original PAF/CFG text, hashes, occurrence/conflict ledgers and exact
comparison values. Absolute acquisition paths describe agent provenance, not user
installation locations or portable configuration defaults.

These templates do not identify a private observation project, choose scientific
associations or activate the new interfaces. Target Mac/Chapman verification is
pending; preserve the earlier accepted examples and source configurations.
